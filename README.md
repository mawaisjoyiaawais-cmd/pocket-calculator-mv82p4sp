# Pocket Calculator

A simple offline calculator with large buttons, instant results, calculation history, and light or dark themes. Built for Android using Python and Kivy 2.3.0.

## Screens
- **Launch** — Initialize local settings and calculation history.
- **Calculator** — Perform everyday calculations quickly.
- **History** — Find and reuse previous calculations.
- **Calculation Details** — Inspect or reuse a saved calculation.
- **Settings** — Customize the calculator and manage local data.
